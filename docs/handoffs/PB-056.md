## The durable half: `tests/copy/pronouns.test.ts`

Correcting six strings is worth little on its own — they had been wrong for weeks and
nothing noticed. **The guard is the actual deliverable.** It scans every string literal
in `src/` and fails with a file, a line and the offending text.

Things about it a future reader needs to know:

- **It hand-rolls a tokeniser.** TypeScript 7 dropped the legacy compiler API —
  `ts.createSourceFile` does not exist in `typescript@7.0.2` — so the AST route is
  closed. A naive regex over raw source flags every comment in the repo and then gets
  neutered until it catches nothing; and an apostrophe in `// Joe's own words` opens a
  fake string literal that swallows the rest of the file. Hence a state machine, and
  hence **the scanner is itself tested six ways** before it is trusted.
- **It guards strings, not comments,** deliberately. A comment guard would be a
  permanent tax on writing about Fred, about Joe, or about real animal sex, and would
  catch nothing a child can read.
- **`male`/`female` are NOT in the pattern.** The teacher's voice is female by ruling
  and `joe/species-facts.json` teaches real dimorphism ("Male deer grow new antlers").
  Banning the adjectives would forbid both.
- **The allowlist has four entries and each carries its reason** — `him`/`his`/`son`
  are phonics vocabulary (`golden.json`, FROZEN, pins 209 deals of them), and two
  developer-facing strings attribute quotations to Joe. A fifth test asserts every
  excuse still matches something real, so the list cannot rot into a list of things
  that used to be true.
- **Revert-checked.** Putting `'Pins her exactly where she is.'` back turns it red with
  `island/grownups.ts:311`. A second, stronger assertion lives in
  `tests/island/grownups.test.ts` and drives the REAL jsdom panel, asserting the whole
  rendered subtree carries no pronoun at all — because the heading, the note and the
  three mode descriptions come from three different places and only the DOM sees all
  of them at once.

## Rules applied to referents (this is the part that needed judgement)

- **The child → singular "they"**, or "the child" wherever "they" would be ambiguous.
  UK English; the grammar was made to read naturally, not mechanically.
- **Fred stays male.** Untouched everywhere.
- **Joe stays male.** He is a real man; comments about him keep his pronouns.
- **A generic parent became neutral** — "what a parent is told about his daughter"
  became "about their child".
- **Pets lost their gender entirely.** `album.ts` alone had 17. Preference was to
  reword to the noun ("the friend", "the pet", "its name") rather than a cold bare
  "it", because the child loves these creatures. **Note the trap: the child NAMES the
  pets, so a name must never imply a pronoun**, and now that the child is also "they",
  pet prose has to say "the child" explicitly or the referent goes ambiguous.
- **Real animal biology stays** — the male hen harrier is grey, the female slow worm
  carries that marking. That is species dimorphism, not a pet's identity.
- **The owl** was not invented. It does not exist in `src/` at all. See "Needs Joe".

## Mechanical constraint that made this safe

**Every file's line count is unchanged.** Enforced on every worker and verified after
the fact with `git diff --numstat | awk '$1!=$2'`, which returns empty. This matters
because `tests/core/verbatim.test.ts` and `tools/golden/capture.mjs` slice files by
line range, several comments cite `file:line`, and `golden.json` is frozen. Comment
blocks were rewrapped in place rather than allowed to grow.

`tools/golden/golden.json` was **not touched** — confirmed by `git status`. It was never
at risk: its 214 matches are all `"w": "his"` / `"w": "him"` / `"w": "lass"` word-deal
entries, i.e. phonics vocabulary, never a reference to a person.

## Landmines learned (promote the durable ones into `docs/HANDOFF.md` §6)

- **TypeScript 7 has no legacy compiler API.** `ts.createSourceFile` is gone in
  `typescript@7.0.2`. Any tool that wanted to parse TS from a test must hand-roll or
  find another route. Cost 20 minutes to discover.
- **Subagents sharing one worktree will trample each other.** Two workers ran
  `git stash` / `git checkout` to investigate an unrelated failure and wiped their
  siblings' uncommitted work; both re-applied it, and one left a stash behind. **Never
  let a worker run `git stash`, `git checkout` or `git reset` in a shared tree**, and
  commit in slices so a mistake costs one slice. Say this in every worker brief.
- **`tests/island/pettap.test.ts` fails under full-suite ordering and passes alone.**
  Pre-existing, unrelated to this card, but it will waste your time if you meet it cold.
  It passed in the full run here; treat an isolated failure as ordering, not logic.
- **Introducing an apostrophe into a single-quoted string in a `.mjs` file** ("does the
  child's school say…") is a syntax error that surfaces much later as *"server never
  announced itself"*. Run `node --check` on any `.mjs` you edit prose in.
- **A test title can be cited from `src/`.** `src/island/world/coast.ts:568` quoted
  `tests/island/coast.test.ts:952` verbatim; renaming one silently desynchronises the
  pair. Grep every renamed title across `src/`, `tests/`, `docs/` AND `joe/` before
  renaming. Two more citations were found the same way in `src/island/world/props.ts`.
- **Comments quote other comments.** `tests/island/pettap.test.ts:676` quoted
  `src/island/picking.ts`; `src/island/species/kit.ts` quoted `recolour.ts`. When you
  rewrite prose in bulk, quoted pairs drift apart unless you look for them.
